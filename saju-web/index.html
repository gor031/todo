ℹ️ 사주팔자란?

사주팔자(四柱八字)는 사람이 태어난 연(年), 월(月), 일(日), 시(時)를 천간(天干)과 지지(地支)로 나타낸 것으로, 총 8글자로 이루어져 있습니다.

이를 통해 타고난 성격, 재능, 운세 등을 파악할 수 있습니다.

✨ 제공 기능
  • 📅 사주팔자 계산 (년주, 월주, 일주, 시주)
  • 🌿 오행 분석 (목, 화, 토, 금, 수)
  • ⭐ 십성 분석 (비겁, 식상, 재성, 관성, 인성)
  • 🎯 신살 분석 (천을귀인, 역마살, 도화살 등)
  • 🔄 대운, 세운, 월운 확인
  • 💕 궁합 보기 (100점 만점)
